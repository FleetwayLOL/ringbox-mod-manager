========================================================
RINGBOX — С ЧЕГО НАЧАТЬ
========================================================

Это архив проекта RingBox: менеджер модов для Android-билда
декомпиляции Sonic Mania (RSDKv5).

--------------------------------------------------------
ЧТО ВНУТРИ
--------------------------------------------------------
START-HERE.txt          <- этот файл
README.md               <- готовый README для GitHub, копируй в репозиторий

pack/
  1-idea.txt            <- СУТЬ ПРОЕКТА. Читать первым.
  2-icon.png            <- иконка 1024x1024
  3-ai-handoff.txt      <- бриф для ИИ, который будет писать код
  4-description.txt     <- описания: GitHub, README, посты (RU + EN)

icon/
  ringbox-1024/512/192/96/48.png   <- размеры иконки
  android/mipmap-*/                <- ic_launcher.png + круглая версия
                                      (готово копировать в res/)

art/
  city-background.png   <- фон (нарисован кодом)
  source-transparent.png<- item box с кольцом, прозрачный фон
  source-on-dark.png    <- он же на тёмной подложке

src/
  sprite.py             <- пиксель-арт монитора, 64x64
  citybg.py             <- пиксель-арт неонового города, 128x128
  make_icon.py          <- сборка иконки (фон + блюр + монитор)
  zones.py              <- палитры зон (на будущее, для тем в приложении)
  render.py             <- рендер иконок по зонам (экспериментальное)
  tools/import_backdrop.py <- импорт своих фонов

ringbox-icon.png        <- итоговая иконка
ringbox-source-vs-result.png <- фон и результат рядом

--------------------------------------------------------
ПОРЯДОК ДЕЙСТВИЙ
--------------------------------------------------------
1. Создать репозиторий на GitHub:
      name:        ringbox
      description: Mod manager for the Sonic Mania decompilation
                   (RSDKv5) on Android — one-tap installs from GameBanana
      Public, Add README: On, .gitignore: Android, License: MIT

2. Скопировать README.md из этого архива в корень репозитория.

3. Папку icon/android/mipmap-* закинуть в app/src/main/res/
   (когда появится Android-проект).

4. Открыть 3-ai-handoff.txt и отдать его ИИ-агенту вместе
   с 1-idea.txt — он начнёт писать код по шагам.

5. Первый экран, который надо сделать: выбор папки игры через SAF
   с проверкой наличия Data.rsdk. Пока он не работает — остальное
   делать бессмысленно.

--------------------------------------------------------
ГЛАВНОЕ, ЧТОБЫ НЕ ПОТЕРЯТЬ
--------------------------------------------------------
• Данные декомпиляции лежат в /storage/emulated/0/RSDK/v5/
  То есть НЕ в Android/data — поэтому SAF работает и root не нужен.
• В mod.ini нужен TargetVersion=5, иначе мод сам отключается.
• Моды грузятся СНИЗУ ВВЕРХ — порядок в списке это порядок загрузки.
• GameBanana: game id 6045, эндпоинты в 1-idea.txt, раздел 4.
  Проверены, работают, не выдумывать новые.
• Не вкладывать в APK Data.rsdk, не хостить моды, не брать
  спрайты Sega. Всё это в APK = жалоба и снятие проекта.

ПЕРЕСОБРАТЬ ИКОНКУ
--------------------------------------------------------
    python3 -m pip install cairosvg pillow

    BLUR      — глубина расфокуса фона (сейчас 16)
    BOX_SCALE — ширина монитора (0.58)
    BOTTOM    — высота подставки (0.905)
    GLOW      — цвет неонового ореола
