ТВОЯ ЗАДАЧА
--------------------------------------------------------
Написать Android-приложение RingBox (Kotlin + Jetpack Compose):
менеджер модов для Android-билда ДЕКОМПИЛЯЦИИ Sonic Mania
(RSDKv5 / Retro Engine, проект Rubberduckycooly).

ТЕРМИНОЛОГИЯ — не путать:
  • декомпиляция RSDKv5 — наш случай: открытый движок, Android-билд,
    игра запускается со своим Data.rsdk;
  • официальная мобильная версия (Netflix) — закрытая, моды не ставятся;
  • Steam/консоли — другой бинарник.
В текстах приложения и README писать «декомпиляция», а не «мобильная
версия» и не «mobile port».

Минимальный рабочий продукт (MVP):

  1. Экран выбора папки игры через SAF
     (ACTION_OPEN_DOCUMENT_TREE + takePersistableUriPermission).
     Валидация: в выбранной папке должен быть Data.rsdk.
     Если папка внутри Android/data — сказать «не поддерживается».

  2. Каталог модов с GameBanana (game id = 6045):
     сетка карточек, поиск, кэш в Room.
     Эндпоинты — в 1-idea.txt, раздел 4. Они рабочие, не выдумывай новые.

  3. Установка в один тап:
     скачать файл → проверить MD5 → распаковать в mods/<ИмяМода>/
     → нормализовать структуру (в архиве может быть вложенная папка,
     вырезать __MACOSX и .DS_Store) → дописать TargetVersion=5
     в mod.ini, если строки нет → добавить мод в конец списка загрузки.

  4. Экран «Установленные»: список, вкл/выкл, перетаскивание порядка
     (моды загружаются СНИЗУ ВВЕРХ), удаление.

--------------------------------------------------------
ПРАВИЛА, КОТОРЫЕ НЕЛЬЗЯ НАРУШАТЬ
--------------------------------------------------------
1. Никаких ассетов Sega. Ни Data.rsdk, ни спрайтов, ни шрифтов
   из игры. Пользователь приносит файлы игры сам.
2. Не хостить моды. Только ссылки на GameBanana.
3. Не трогать папку Android/data — SAF туда не имеет доступа.
   Работаем только с общим хранилищем (/storage/emulated/0/RSDK/v5).
4. Не сливать каталог в один запрос: у GameBanana пагинация
   (_nPerpage ≤ 50) и лимиты. Кэшируй, не спамь.
5. Всегда проверять MD5 скачанного файла. Битые загрузки — главная
   причина «мод не работает».
6. Ошибки показывать человеческим языком: «в папке нет Data.rsdk,
   выбери папку v5 целиком», а не «SecurityException».

ПРОВЕРЕННЫЕ ФАКТЫ (НЕ ПЕРЕПРОВЕРЯЙ, ТРАТИШЬ ВРЕМЯ)
--------------------------------------------------------
• GameBanana game id для Sonic Mania = 6045
• https://gamebanana.com/apiv11/Util/Game/NameMatch?_sName=Sonic%20Mania
• https://gamebanana.com/apiv11/Mod/Index?_aFilters[Generic_Game]=6045&_nPerpage=50&_nPage=1
  → ~1423 мода
• https://gamebanana.com/apiv11/Mod/{id}/DownloadPage
  → _aFiles[]: _sFile, _nFilesize, _sDownloadUrl, _sMd5Checksum
• прямая ссылка https://gamebanana.com/dl/{fileId} — работает с User-Agent браузера
• путь данных Android-билда декомпиляции:
  /storage/emulated/0/RSDK/v5/ (Data.rsdk, mods/, Settings.ini)
• совместимость: часть модов сделана под Steam-версию, но работает
  и в декомпиляции; предупреждать, если TargetVersion не совпадает
• структура мода: mods/<Имя>/mod.ini + папка Data/ (опционально)
• без TargetVersion=5 в mod.ini мод отключается сам
• порядок загрузки: снизу вверх, хранится в списке модов/modconfig.ini

Шаг 6. Обновления, ошибки, полировка.
