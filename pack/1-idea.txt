RINGBOX — ИДЕЯ ПРОЕКТА
версия документа: 1.0 (2026-11-07)
========================================================

--------------------------------------------------------
1. ЧТО ЭТО
--------------------------------------------------------
RingBox — Android-приложение, менеджер модов для ДЕКОМПИЛЯЦИИ
Sonic Mania (RSDKv5 / Retro Engine), а именно её Android-билда.

Терминология — важно, не путать три разные вещи:
  • декомпиляция RSDKv5 (Rubberduckycooly/Sonic-Mania-Decompilation)
    — открытый движок, который собирают под Android, iOS, Switch
    и т.д. Игра запускается на нём при условии, что пользователь
    положил свой Data.rsdk. НАША ЦЕЛЬ — именно это;
  • официальная мобильная версия (Sonic Mania Plus через Netflix) —
    закрытая, моды туда не ставятся, мы с ней не работаем;
  • Steam/консольная сборка — другой бинарник, моды у неё свои
    (хотя часть модов совместима, это отдельная история).

Отсюда правило речи: НЕ «мобильная версия», НЕ «мобильный порт»
в маркетинге. Правильно: «декомпиляция Sonic Mania на Android»
или «Android-билд декомпиляции RSDKv5».

Пользователь один раз указывает папку игры — дальше моды
ставятся в один тап прямо из каталога GameBanana.

Название не случайное: в играх серии этот объект официально
называется Item Box (アイテムボックス), а в мануале Sonic 1
(1991) — Video Monitor. То есть «бокс с кольцами» = RingBox:
честно по лору и без чужих товарных знаков в имени.

--------------------------------------------------------
2. КАКУЮ БОЛЬ СНИМАЕМ
--------------------------------------------------------
Моды в Android-билде декомпиляции ставятся так (сегодня, вручную):

  1. найти мод на GameBanana;
  2. скачать zip;
  3. понять, что внутри архива может быть вложенная папка;
  4. распаковать в /storage/emulated/0/RSDK/v5/mods/<ИмяМода>/
     так, чтобы рядом с Data/ лежал mod.ini;
  5. дописать в mod.ini строку TargetVersion=5, иначе мод
     не подхватится;
  6. запустить игру, открыть Dev Menu, зайти в Mods;
  7. включить мод и выставить приоритет — моды грузятся
     СНИЗУ ВВЕРХ, порядок в списке = порядок загрузки.

Это 15 минут мата, и всё повторяется с каждым модом.

Дополнительная боль: на Android 11+ приложения не имеют
доступа к чужой папке Android/data. Но в этом проекте она
и не нужна — см. пункт 3.

--------------------------------------------------------
3. КЛЮЧЕВОЕ ТЕХНИЧЕСКОЕ ОТКРЫТИЕ
--------------------------------------------------------
Android-билд декомпиляции хранит данные НЕ в Android/data,
а в общем хранилище:

    /storage/emulated/0/RSDK/v5/

Внутри: Data.rsdk, Settings.ini, SaveData.bin,
Achievements.bin и папка mods/.

Значит scoped storage не мешает: пользователь через SAF
(Storage Access Framework) выбирает папку v5, приложение
получает постоянное разрешение и пишет моды как к себе.
Ни root, ни adb, ни Shizuku не нужны.

Пример пути:
    /storage/emulated/0/RSDK/v5/Data.rsdk
    /storage/emulated/0/RSDK/v5/mods/<ИмяМода>/mod.ini

ВАЖНО: если у пользователя сборка, которая держит данные
в Android/data/com.decomp.rsdkv5 — SAF туда не пустит.
Такие случаи надо детектить и честно сообщать, что не
поддерживается, а не падать.

--------------------------------------------------------
4. ПРОВЕРЕННЫЕ ФАКТЫ (НЕ ПЕРЕПРОВЕРЯТЬ)
--------------------------------------------------------
Всё ниже реально дёргалось вручную 2026-11-07.

Каталог GameBanana (публичный API apiv11):

  • поиск игры:
      GET https://gamebanana.com/apiv11/Util/Game/NameMatch?_sName=Sonic%20Mania
      → Sonic Mania, _idRow = 6045

  • список модов игры (пагинация):
      GET https://gamebanana.com/apiv11/Mod/Index
          ?_aFilters[Generic_Game]=6045&_nPerpage=50&_nPage=1
      → на момент проверки 1423 мода
      (в общем сабфиде игры 4525 записей: моды, туториалы,
       випы, запросы — фильтровать по типу)

  • файлы мода и ссылки на скачивание:
      GET https://gamebanana.com/apiv11/Mod/{id}/DownloadPage
      → _aFiles[] с полями:
          _idRow, _sFile, _nFilesize, _sDownloadUrl,
          _sMd5Checksum, _aModManagerIntegrations

  • прямая ссылка вида https://gamebanana.com/dl/{fileId}
    отдаёт файл, если вести себя как браузер (User-Agent).

  • md5 приходит вместе с файлом — обязательно проверять.

Структура мода (эталон):
    mods/
      ИмяМода/
        Data/            <- ассеты (может отсутствовать)
        <LogicFile>.dll  <- логика, если мод с кодом
        mod.ini          <- метаданные

mod.ini содержит как минимум TargetVersion; если его нет —
дописать TargetVersion=5 (иначе мод отключается сам).

Приоритет загрузки: моды грузятся снизу вверх, порядок
хранится в списке модов / modconfig.ini.

--------------------------------------------------------
5. ЧТО ДЕЛАЕТ ПРИЛОЖЕНИЕ (MVP)
--------------------------------------------------------
Экран 1. Выбор папки.
  • Кнопка «Указать папку игры».
  • SAF-диалог, пользователь выбирает .../RSDK/v5.
  • Валидация: внутри должен быть Data.rsdk.
  • Сохраняем persistable URI permission — доступ
    действует после перезапуска.

Экран 2. Каталог.
  • Сетка/список модов из GameBanana (game 6045).
  • Поиск, сортировка, кэш каталога в Room.
  • Карточка: превью, название, автор, размер, обновлено.

Экран 3. Установка.
  • Один тап: скачать → проверить md5 → распаковать
    в mods/<ИмяМода>/ → нормализовать структуру
    (архив может быть с вложенной папкой) → дописать
    TargetVersion=5 при отсутствии → добавить в конец
    списка загрузки.
  • Прогресс и внятные ошибки.

Экран 4. Установленные.
  • Список с переключателями вкл/выкл.
  • Перетаскивание для порядка загрузки (снизу вверх!).
  • Удаление, «открыть папку мода».
  • Проверка обновлений на GameBanana.

Не в MVP: аккаунты, рейтинги, свои загрузки модов.

--------------------------------------------------------
6. СТЕК
--------------------------------------------------------
  • Kotlin, Jetpack Compose, minSdk 26
  • SAF: ACTION_OPEN_DOCUMENT_TREE + takePersistableUriPermission
  • Хранилище: Room (кэш каталога), DataStore (URI папки)
  • Сеть: Retrofit/OkHttp или Ktor
  • Архивы: java.util.zip (нужна поддержка вложенных папок)
  • Фоновые задачи: WorkManager (докачка при обрыве)
  • Дистрибуция: APK сайдлоадом (см. риски)

--------------------------------------------------------
7. РИСКИ И ГРАНИЦЫ (ВАЖНО)
--------------------------------------------------------
Юридические:
  • НЕЛЬЗЯ вкладывать в APK Data.rsdk или любые ассеты игры.
    Пользователь приносит свои файлы сам.
  • НЕЛЬЗЯ хостить моды у себя — только ссылки на GameBanana.
  • НЕЛЬЗЯ использовать спрайты/арт Sega в интерфейсе.
    Иконка и фон нарисованы с нуля (см. citybg.py, sprite.py).
  • Google Play с такой механикой почти наверняка откажет —
    рассчитываем только на APK/сайдлоад.

Продуктовые:
  • Аудитория узкая: те, кто играет в декомпиляцию Mania
    на Android-устройствах.
  • Платить не будут. Это портфолио и репутация, не бизнес.
  • Зато: живое сообщество, быстрый фидбек, реальный прод.

Технические:
  • Версии Data.rsdk (обычная/Plus) влияют на совместимость
    модов — половина «не работает» именно из-за этого.
  • Мод может требовать другой мод-зависимость — ловить
    в mod.ini и предупреждать.
  • Иногда архив содержит мусор (__MACOSX, .DS_Store).
