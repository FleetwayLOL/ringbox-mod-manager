Палитра (mid — текущая)
-------------------------
корпус    #B9BFC7 → #A3AAB3 → #8C939C → #787F88 → #61686F   (средний серый)
кант       #464C54
безель     #262B32 → #15181D
экран      #000000
кольцо     #F2C860 → #E0AE36 → #C68F1E → #9E6E12
индикатор  #8CE39A
фон в UI   #0A0B0F

Правила
-------
- Корпус только серый. Чёрный/графитовый корпус отменён — сливается с фоном.
- Экран внутри — чёрный, без зоны, травы и шахматок.
- Кольцо матовое: две дуги (светлая сверху-слева, тёмная снизу-справа), без свечения.
- Характер дают детали: винты по углам, решётка динамика, зелёный индикатор.
- Не убирать светлую кромку сверху — без неё корпус выглядит плоским.
- На белом фоне ставить на подложку #0A0B0F или светлую #F3F4F7, но не вплотную.
